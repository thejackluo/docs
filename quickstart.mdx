## Install

You need Python 3.12 and a checkout of the vault repository.

```bash
git clone <your vault repository> vault && cd vault
python3 -m venv .venv && .venv/bin/pip install -e ".[dev]"
```

Every command below is `brain <command>`. The tool finds the vault by looking for the nearest folder that contains `schema/`. To point it somewhere else, pass `--root <path>` before the command or set `BRAIN_ROOT`.

## Read

```bash
brain context                      # who the owner is right now, each section with its age
brain context "Orbit"              # a sourced briefing on one topic
brain search "pricing"             # full-text search
brain get projects/orbit           # one node: fields, claims, body, backlinks
brain ask "Why did we drop per-seat pricing?"
```

## Write

```bash
brain capture "Dana Wu #person company:: Kaiser; wants an intro to @arman"
brain add meeting "Orbit pricing sync" -f date=2026-03-02
brain claim projects/orbit "Charges per seat" --source meetings/orbit-pricing-sync --confidence medium
```

`capture` appends to today's journal and creates any typed node the line describes. `claim` adds a fact with its source to a node.

## Open the web app

```bash
BRAIN_PASSWORD=choose-one brain serve --port 8787
```

Open `http://127.0.0.1:8787` and sign in with that password.

## Check your work

```bash
brain lint        # broken links, schema violations, orphans, duplicates
pytest -q         # the test suite
```
