Brain is a private knowledge system for one person. The data is a folder of Markdown files in Git. Everything else, including the search index, the web app and the agent tools, is built from those files and can be rebuilt at any time.

## What it does

- **Stores knowledge as typed nodes.** Every Markdown file is a node with a type such as person, project, belief, decision, meeting or essay. Types define fields, so nodes can be queried like rows.
- **Connects notes automatically.** Names of existing pages are linked when you write, and mentions are indexed even when you do not link them.
- **Answers questions with sources.** Search and Ask return the lines that support an answer, with the note id and line number.
- **Briefs AI agents.** One call returns a dated, sourced pack on a topic, sized for a context window.
- **Pulls from other tools.** Notion syncs both ways. Meeting notes, chat exports, contacts and Google Docs import as sources.

## Two rules that shape everything

1. **Markdown is the source of truth.** The SQLite index is a cache. Delete it and it rebuilds.
2. **The brain explains; it does not overrule.** It is the place for why something happened and who was involved. For current facts such as where the owner lives or how many users a product has, the owner's own record wins, and every briefing shows how old its data is.
